# Foam Products Webpage

## Project Description

A responsive and modern foam products webpage developed using HTML, CSS, and JavaScript. The project includes product sections, styled content, interactive elements, and a functional form with a submit button.

## Features

* Responsive design for desktop and mobile devices
* Clean and modern user interface
* Product-focused sections
* HTML form with submit button
* CSS styling and responsive layout
* JavaScript for interactive functionality
* Navigation and structured webpage sections

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.
4. Explore the responsive webpage and interactive features.
